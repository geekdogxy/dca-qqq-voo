# dca-qqq-voo

VOO + QQQ 长期定投助手：一套规则 + 一段 Prompt，让 AI 按时帮你判断**今天该不该买、买多少、要不要卖**。

- 📐 **规则**：按回撤分档加减倍数的定投策略（见 [Rule.md](./Rule.md)）
- 🔔 **只做提醒**：不自动交易，最终决策权在你
- 🤖 **多 Agent 通用**：Codex / Claude / Grok / Muse / Hermes 都能跑

> 📢 更多 AI 与投资实践，欢迎关注推特 **[@geekxy23](https://x.com/geekxy23)**

## 策略概览

- VOO / QQQ 默认按 **60% / 40%** 买入权重定投
- 每只 ETF 按各自距 ATH 的回撤决定倍数（0.5x ~ 3.0x），跌得越多买得越多
- 股票仓位 ≥ 80% 暂停买入，保留约 20% 现金抄底
- 回撤 ≤ 3%、VIX < 15、恐贪指数 > 75、仓位 ≥ 40% 同时满足时，提醒卖出 5%

完整规则、数据来源与风险提示见 [Rule.md](./Rule.md)。

## 使用

可以使用 Codex、Claude、Grok、Muse、Hermes 等工具配置**定时任务**，把下面的 Prompt 交给它即可。Prompt 可以根据你的实际情况优化（金额、比例、频率、返回格式等）。

````text
周一 周三 周五早上上海时间11点跑一个定时任务 参考 Rule.md 定投策略 提醒我是否买入 卖出

当前定投金额 BASE = 500 USD
当前定投比例 VOO / QQQ 当前为 60% / 40%

获取数据可以参考文档 如果失败 可以使用其他方法

最终返回参考

```
1. 建议：

Buy/Sell VOO 456 USD
Sell/Sell QQQ 123 USD

其他
超过80%停止Buy 或者 低于40%停止Sell 或者其他

2. 分析：

VOO 回撤: 13.3% / ATH: 750 / LastClose: 650
QQQ 回撤: 13.3% / ATH: 750 / LastClose: 650

给出分析+建议原因

```
````

### 小提示

- 使用前把 `BASE` 和 VOO / QQQ 比例改成自己的数值
- 如需读取真实持仓，可接入券商 API / MCP（如 IBKR MCP），否则请在 Prompt 中手动提供仓位
- 数据源（yfinance、CNN 恐贪指数）失败时让 Agent 换其他方式获取，恐贪指数拿不到则不触发卖出提醒
